# 개발 가이드

## 구조

[Feature-Sliced Design 2.1](https://feature-sliced.design)을 따릅니다. 화면이 한 페이지뿐이라 한 곳에서만 쓰는 코드는 모두 `pages/simulator` 슬라이스 안에 두고(pages-first), 여러 곳에서 쓰는 UI와 유틸만 `shared`에 둡니다. `pnpm lint:fsd`(Steiger)로 검사하며 `src/routes`, `src/router.tsx`, 생성 파일은 검사에서 뺍니다.

| 위치                                        | 내용                                                                                   |
| ------------------------------------------- | -------------------------------------------------------------------------------------- |
| `src/routes/`                               | TanStack Router 파일 라우트. `index.tsx`는 `SimulatorPage`를 연결만 합니다             |
| `src/app/`                                  | 전역 CSS(Tailwind 테마 토큰), HTML 문서 틀(`lang="ko"`)                                |
| `pages/simulator/model/world/`              | 시뮬레이션 엔진(순수 함수)·시나리오·시간·zustand 스토어                                |
| `pages/simulator/model/site/`, `structure/` | 도시·화산·해구·해협·빙하 데이터, 거대 구조물 목록                                      |
| `pages/simulator/model/frame.ts`            | 스토어 상태 → 매 프레임 셰이더 입력(태양 방향, 파면, 화산재, 폭풍)                     |
| `pages/simulator/lib/shaders.ts`            | 지구·구름·대기 GLSL                                                                    |
| `pages/simulator/ui/globe/`                 | Canvas, 카메라 조작, 지구, 마커, 구조물, 분출 기둥                                     |
| `shared/ui/`                                | Button, Tabs, RangeField, SelectField, ChoiceGroup, StatusMessage (옆에 스토리·테스트) |
| `shared/lib/`                               | 위경도 ↔ 3D 좌표, 대권 거리, 태양 직하점·계절, 숫자 서식                               |

3D 화면은 `ClientOnly` + `lazy`로 브라우저에서만 불러오고, 나머지 화면은 빌드 때 HTML로 사전 렌더링합니다(`dist/client`, 정적 호스팅 가능).

## 시뮬레이션 모델 (단순화)

| 항목        | 계산                                                                                                                                    |
| ----------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| 해수면      | 현재 속도 3.7mm/년 + 2차 곡선. 2100년 값이 시나리오(0.44 / 0.56 / 0.77 / 1.6m)와 맞게 정함. 빙하 커튼·우주 차양이 속도를 줄임(최대 80%) |
| 기온        | 2020년 +1.2°C에서 2100년 시나리오 값까지 선형. 우주 차양 −0.8°C, VEI 6·7·8 분화는 −0.4·−1.0·−3.0°C에서 1.5년 시간상수로 회복            |
| 도시 침수   | 해수면이 저지대 고도보다 높고, 기존 방어(델타 웍스 등)·방조제·해협 댐 높이보다 높으면 침수. 1m 안쪽이면 위험                            |
| 침수 면적   | 육지 고도 격자의 0m~해수면 구간 면적(위도 가중) × 육지 면적 1억 4,894만 km²                                                             |
| 화산        | 화산재 반경 VEI 4~8: 150 / 350 / 700 / 1,500 / 3,000km. 감압 시추가 VEI를 2 낮춤                                                        |
| 쓰나미      | 진원 파고 6m × 10^(0.5(Mw−8)), 거리 d에서 × √(150/d). 같은 바다(분지)의 도시만, 시속 700km. 3m 이상 큰 피해, 방벽 높이 이하면 막음      |
| 열대 저기압 | 연 85개 × (1 + 0.06 × 추가 온난화), 계절별 발생 해역, 서진 후 전향, 최대 8개 표시                                                       |
| 시각        | 하루가 1초보다 빨리 지나는 속도(1개월/초 이상)에서는 낮·밤 깜빡임을 막으려고 시각을 고정                                                |

## 셰이더

지구 셰이더 하나가 순서대로 처리합니다: 건조화(초록 지대 → 갈색) → 계절 적설선·만년설 → 침수(R 채널 고도 < 해수면) → 해빙 → 화산재 → 태양광(낮·밤, 바다 반사, 박명) → 밤 불빛(침수·화산재 지역 소등) → 쓰나미 파면 → 대기 가장자리. 구름 셰이더는 알파 채널 구름을 두 겹으로 흘리고 폭풍 위치에 나선을 그립니다.

## 접근성

- 3D 지구는 마우스 없이도 씁니다: 지구본 영역에 초점을 두고 화살표·`+`/`-` 키, 같은 기능의 버튼, "지점으로 이동" 목록.
- 자동 회전은 끌 수 있고, 운영체제의 '동작 줄이기'가 켜져 있으면 처음부터 꺼집니다. 시뮬레이션은 멈춘 상태로 시작합니다.
- 탭은 APG 패턴(화살표·Home·End, roving tabindex), 결과는 `role="status"`로 알립니다. 슬라이더 값은 `aria-valuetext`로 전달합니다.
- 상태는 색과 글자(침수·보호 중·위험, 경보·주의·완료)로 함께 표시하고, 마커는 종류별로 모양이 다릅니다.
