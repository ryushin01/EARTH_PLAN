# 개발 가이드

## 구조

[Feature-Sliced Design 2.1](https://feature-sliced.design)을 따릅니다. 시뮬레이터 화면에서만 쓰는 코드는 모두 `pages/simulator` 슬라이스 안에 두고(pages-first), 없는 주소 안내는 `pages/not-found`, 여러 곳에서 쓰는 UI와 유틸만 `shared`에 둡니다. `pnpm lint:fsd`(Steiger)로 검사하며 `src/routes`, `src/router.tsx`, 생성 파일은 검사에서 뺍니다.

| 위치                                        | 내용                                                                                                                                                                            |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src/routes/`                               | TanStack Router 파일 라우트. `index.tsx`는 `SimulatorPage`를 연결만 합니다                                                                                                      |
| `src/app/`                                  | 전역 CSS(Tailwind 테마 토큰), HTML 문서 틀(`lang="ko"`), 오류 화면(`AppErrorPage`, 라우터 기본 오류 화면), 배포 뒤 옛 코드 조각을 받지 못하면 새로고침(`useReloadOnStaleBuild`) |
| `src/pages/not-found/`                      | 없는 주소 안내(`NotFoundPage`, 라우터 기본 404 화면)                                                                                                                            |
| `pages/simulator/model/world/`              | 시뮬레이션 엔진(순수 함수)·재해 계산·시나리오·시간·zustand 스토어, 화면 표시용으로 솎은 상태(`sampled.ts`)                                                                      |
| `pages/simulator/model/site/`, `structure/` | 도시·화산·해구·해협·빙하 데이터, 거대 구조물 목록                                                                                                                               |
| `pages/simulator/model/frame.ts`            | 스토어 상태 → 매 프레임 셰이더 입력(태양 방향, 파면, 화산재, 폭풍, 오로라)                                                                                                      |
| `pages/simulator/lib/shaders.ts`            | 지구·구름·대기 GLSL                                                                                                                                                             |
| `pages/simulator/ui/globe/`                 | 지구본 화면(`GlobeViewport`: 정지 이미지·조작 버튼), 3D 묶음(`GlobeCanvas`: Canvas·장면), 지구, 마커, 구조물, 분출 기둥 (옆에 스토리·테스트, 스토리 전용 3D 무대 `StoryStage`)  |
| `shared/ui/`                                | Button(`buttonClasses`로 버튼 모양 링크도), Tabs, RangeField, SelectField, ChoiceGroup, StatusMessage, MessageScreen(404·오류 안내 틀) (옆에 스토리·테스트)                     |
| `shared/lib/`                               | 위경도 ↔ 3D 좌표, 대권 거리, 태양 직하점·계절, 숫자 서식                                                                                                                        |

화면은 빌드 때 HTML로 사전 렌더링합니다(`dist/client`, 정적 호스팅 가능). three.js를 쓰는 `GlobeCanvas`만 `lazy`로 따로 받습니다.

### 화면 갱신 솎기

재생 중에는 시뮬레이션 시각이 매 프레임 바뀝니다. 화면 패널(탭 패널은 숨겨져도 마운트돼 있음)이 스토어를 그대로 구독하면 프레임마다 모두 다시 그리므로, 패널은 `useWorld` 대신 `useWorldSampled`(`model/world/sampled.ts`)로 읽습니다.

- 사본 스토어가 `useWorld`를 구독해, 시간 진행(`tick`, `isTicking()`)에서 나온 변경은 100ms(`SAMPLE_MS`)마다 한 번, 사용자 조작(건설·슬라이더·재생 버튼 등)은 바로 옮깁니다. 한 프레임 안의 진행·사건·미션 변경이 끝난 뒤 옮기도록 늘 타이머로 미룹니다.
- 3D 장면은 지금처럼 `useWorld.getState()`로 매 프레임 직접 읽고, 동작(함수)은 어느 쪽에서 읽어도 같습니다.

### 지구본 정지 이미지

지구본 화면은 처음에 3D 첫 화면과 같은 시점·시각에서 찍은 정지 이미지(`ui/globe/poster/earth-{600,800,1200}.webp`)를 보여 줍니다. 첫 상호작용(포인터·키·휠·터치·스크롤·초점)이 있거나 5초가 지나면 3D를 그립니다. 지구가 처음 보이면(`Planet`의 `onReady`) 이미지를 흐리게 지웁니다.

- 페이지를 다 받고(`load`) 1초 뒤 한가할 때(`requestIdleCallback`) 3D 묶음을 불러 두고 텍스처를 미리 받아 해석합니다(`preloadGlobe` → R3F `useLoader.preload`). 그리는 일은 하지 않습니다. 첫 화면 그리기와 겹치면 LCP가 늦어져서 미룹니다. 데이터 절약 모드(`navigator.connection.saveData`)나 2G급 회선에서는 미리 받지 않고, 데이터 절약 모드에서는 5초 뒤 저절로 그리지도 않습니다.
- 페이지가 준비(하이드레이션)되기 전의 첫 입력은 문서 머리의 짧은 인라인 스크립트(`EARLY_WAKE_SCRIPT`, `routes/index.tsx`의 `head`)가 기록해 두고, 준비되자마자 3D를 그립니다.

- 시작 시각이 고정(2026-11-12 03:00 UTC)이고 시뮬레이션이 멈춘 채 시작하므로 첫 3D 화면과 같습니다. 자동 회전은 지구가 보인 뒤에 시작하고, 그 전에 누른 회전·확대는 모아 두었다가 실행합니다.
- 공유 링크(`?s=`)로 열면 상태가 처음과 다르므로 이미지 없이 바로 3D를 받습니다.
- 3D를 그리지 못하면(WebGL 없음 등) 이미지를 그대로 두고 이유를 상태 메시지로 알립니다.
- 셰이더, 텍스처, 시작 시각, 처음 카메라, 지점 표시가 바뀌면 `pnpm storybook`을 띄운 뒤 `pnpm poster`로 다시 찍습니다. Storybook의 `GlobeCanvas › Poster` 스토리(별 없음, 1200px)를 찍어 브라우저의 WebP 인코더로 1200·800·600px를 만듭니다.

## 셰이더

지구 셰이더 하나가 순서대로 처리합니다: 건조화(초록 지대 → 갈색) → 계절 적설선·만년설 → 침수(R 채널 고도 < 해수면, 한반도는 1분 고도 패치) → 해빙 → 화산재 → 태양광(낮·밤, 바다 반사, 박명) → 밤 불빛(침수·화산재 지역 소등) → 오로라(밤에만) → 쓰나미 파면 → 대기 가장자리. 가뭄 지역은 건조화 다음에, 산불(탄 자리·연기)은 화산재 다음에 처리하고 불길은 밤에 더 밝게 더합니다. 구름 셰이더는 알파 채널 구름을 두 겹으로 흘리고 폭풍 위치에 나선을 그립니다. 소행성 불덩이·충격파 고리는 3D 메시로 그립니다.

텍스처는 `ImageBitmapLoader`로 메인 스레드 밖에서 해석하고, 셰이더는 `compileAsync`로 미리 컴파일한 뒤 지구를 보여 줍니다.

- 한반도 고도 패치(`korea-elevation.webp`)는 지구가 보인 뒤에 받아 `uDetail`에 넣고, 패치 범위(`uDetailRect`, 텍스처 좌표) 안에서 침수 판정 고도를 바꿉니다. 가장자리는 전 세계 고도와 부드럽게 섞고, 육지·바다 구분과 색은 전 세계 텍스처를 씁니다([데이터 출처](data-sources.md#한반도-고해상도-고도)).
- 오로라는 지자기 극 방향(`uMagPole`)에 대한 위도로 띠를 정하고, 고리 좌표(cos, sin)로 만든 노이즈로 커튼과 세로 광선을 그립니다(한 바퀴 도는 곳에 이음매가 없음).
- 분출 기둥·충돌·지진파 고리는 크기가 매 프레임 바뀌므로 도형 인자(`args`)로 넘기지 않습니다. 인자가 바뀌면 React Three Fiber가 도형을 새로 만들기 때문입니다. 구는 반지름 1로 만들어 `scale`로, 두께가 일정한 고리와 위가 넓어지는 기둥은 한 번 만든 도형의 정점만 고칩니다(`Ring`, `Tube`).
- React Three Fiber 9는 `<shaderMaterial uniforms={...}>`의 항목을 재질 쪽 객체로 복사합니다. 처음에 넘긴 객체를 나중에 고치면 셰이더에 반영되지 않으므로, 마운트 뒤에 바꾸는 값은 재질(`ref.current.uniforms`)에 씁니다.

## 설치·캐시

- `public/manifest.webmanifest`, 아이콘(192·512·maskable·apple-touch)으로 홈 화면에 설치할 수 있습니다.
- `public/sw.js`는 프로덕션에서만 등록합니다. 페이지는 네트워크 먼저(끊기면 캐시, 404 응답은 저장하지 않음), `assets/`·`textures/`는 캐시 먼저, Storybook은 건드리지 않습니다.
- 캐시 이름의 버전은 빌드할 때 Vite 플러그인(`scripts/vite-sw-version.ts`)이 채웁니다. 코드(`assets/`)는 파일 이름에 해시가 있으므로 이름 목록으로, 텍스처는 이름이 그대로이므로 내용으로 만듭니다. 새 서비스 워커가 켜지면 이름이 다른 옛 캐시를 지웁니다. 손으로 버전을 올릴 일은 없습니다.
- 배포 직후 열려 있던 옛 화면이 사라진 코드 조각을 받지 못하면(`vite:preloadError`) 한 번 새로고침합니다. 1분 안에 다시 실패하면 반복하지 않습니다(`sessionStorage`).
- 작은 화면(767px 이하)이나 메모리 2GB 이하 기기는 `TEXTURES_SMALL`(1024px)을 씁니다. 고도 텍스처는 값이 계산에 쓰이므로 최근접으로 줄이고 무손실로 저장했습니다.

## 언어

- `shared/i18n`: 언어 상태(zustand, `localStorage`에 기억)와 `<html lang>` 동기화, 보간 함수
- `pages/simulator/ui/messages.ts`: 화면 문구를 키마다 `[한국어, 영어]` 쌍으로 적고 `useT()`의 `t(키, 값)`로 씀. 두 언어의 `{자리}`가 같은지 테스트로 검사
- `model/site/en.ts`, `STRUCTURE_EN`, `labelEn`: 데이터의 영어 이름·설명
- 사건 기록·결과 메시지는 생길 때 `{ ko, en }`을 함께 만들고(`model/text.ts`의 `compose`), 화면에서 현재 언어를 고름

## 웹 폰트

영문·숫자는 Sora(`@fontsource-variable/sora`), 한글은 페이퍼로지를 씁니다. 전역 CSS(`src/app/styles/index.css`)의 `--font-sans`·`--font-display`가 둘 다 `'Sora Variable', 'Paperlogy', …` 순서라 영문·숫자는 Sora, 한글은 페이퍼로지로 그립니다.

페이퍼로지는 저장소에 넣어 같은 사이트에서 제공합니다.

- `scripts/fonts/paperlogy/`: 원본(400·600·700)과 라이선스. `scripts/fonts/config.json`: 글꼴·굵기·글자를 찾을 폴더. `scripts/fonts/ko-slices.json`: Google Fonts 한국어 글꼴의 글자 묶음(124개).
- `pnpm fonts`가 `src/app/styles/fonts/`에 두 가지를 만듭니다.
  - `paperlogy.css`, `paperlogy/paperlogy-<굵기>-ui.woff2`: 소스의 문자열·템플릿·JSX 글자(주석 제외)와 JSON에 쓰인 한글·기호만 담은 파일입니다. 전역 CSS가 불러와 첫 화면과 함께 받습니다.
  - `paperlogy-rest.css`, `paperlogy/paperlogy-<굵기>-<번호>.woff2`: 나머지 글자를 글자 묶음별로 나눈 조각입니다. `RootDocument`의 `useRestFonts`가 페이지를 다 받고 1초 뒤 한가할 때 낮은 우선순위로 붙이고, 브라우저는 화면에 쓴 글자가 든 조각만 받습니다(사용자가 입력한 시나리오 이름 등). 화면 글자 파일에 있는 글자는 `unicode-range`에서 빼서 두 번 받지 않습니다.
- 화면 글자를 바꾸면 `pnpm fonts`를 다시 실행합니다. 빠진 글자가 있으면 `src/app/styles/fonts.test.ts`가 실패합니다(빠진 글자도 나머지 조각으로 보이지만 늦게 받습니다). 조각 파일은 글자가 바뀌어도 그대로라 없는 것만 만들고, 원본 글꼴을 바꾸면 `pnpm fonts --all`로 모두 다시 만듭니다.
- 작은 조각(대부분 4KB 미만)을 Vite가 CSS에 base64로 넣지 않도록 `vite.config.ts`의 `assetsInlineLimit`에서 woff2를 뺍니다.
- 생성한 CSS는 Prettier 검사에서 뺍니다(`.prettierignore`).

## 의존성 업데이트

Dependabot(`.github/dependabot.yml`)이 매주 월요일 오전 9시(한국 시각)에 npm(pnpm)과 GitHub Actions 업데이트 PR을 엽니다. 개발 도구와 배포 의존성의 부·수 버전은 각각 한 PR로 묶고, 공개 뒤 3일이 지난 판만 올립니다(pnpm의 공개 대기 기간 1일보다 넉넉히). 보안 알림과 보안 업데이트 PR도 켜 두었습니다. CI가 통과하면 검토해 합칩니다.

## 접근성

- 3D 지구는 마우스 없이도 씁니다: 지구본 영역에 초점을 두고 화살표·`+`/`-` 키, 같은 기능의 버튼, "지점으로 이동" 목록.
- 자동 회전은 끌 수 있고, 운영체제의 '동작 줄이기'가 켜져 있으면 처음부터 꺼집니다. 시뮬레이션은 멈춘 상태로 시작합니다.
- 탭은 APG 패턴(화살표·Home·End, roving tabindex), 결과는 `role="status"`로 알립니다. 슬라이더 값은 `aria-valuetext`로 전달합니다.
- 사건 기록의 알림(`role="status"`)은 3초(`ANNOUNCE_MS`) 안에 생긴 사건을 모아 "새 사건 N건. 가장 최근 사건"으로 한 번만 읽습니다. 빠르게 재생해도 알림이 쉬지 않고 이어지지 않습니다.
- 셀렉트는 브라우저 기본 화살표 대신 직접 그린 화살표(꾸밈, `aria-hidden`, `pointer-events: none`)를 써서, 화살표와 칸 오른쪽 끝 간격을 글자와 칸 왼쪽 끝 간격(테두리 1px + 여백 12px)과 같게 맞춥니다.
- 상태는 색과 글자(침수·보호 중·위험, 경보·주의·완료)로 함께 표시하고, 마커는 종류별로 모양이 다릅니다.
